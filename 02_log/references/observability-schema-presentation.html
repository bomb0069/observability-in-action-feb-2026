✗
Request count / Error count

✗
นับ 5xx ต่อ route
label: method, route, status_code ตอบได้ทุกมิติโดยไม่ต้องเขียน log
✗
Throughput per minute

ย้ายไป Traces
✗
Response time / Processing time ต่อ request
Trace บอกได้เป๊ะกว่าว่า latency อยู่ที่ span ไหน
✗
Function A เรียก Function B
Call chain เห็นได้ใน trace ข้าม service ด้วย ไม่ใช่แค่ใน service เดียว
✗
"Started processing…" / "Finished processing…"

Log Schema
Log level usage guide
4 levels เท่านั้น lowercase เท่านั้น
Levelใช้เมื่อProduction volumeตัวอย่างContext ที่ต้องมี
error เกิดเหตุการณ์ที่ต้องการ action ทันที ต่ำ < 0.1% payment_failed, db_connection_lost ต้องมี full context เสมอ
warn ผิดปกติแต่ยัง recover ได้ / retry สำเร็จ ต่ำ < 1% retry_succeeded, rate_limit_near บอก why มัน warn
info Business events ที่มีความหมาย เท่านั้น ปานกลาง order_placed, user_signup entity_id + actor_id
debug ปิดใน prod — เปิดเฉพาะตอน debug ปิดใน prod cache_miss, sql_query_plan —
Anti-patterns ที่ต้องหลีกเลี่ยง
✗
log ทุก request (ย้ายไป Metrics)
✗
interpolate variable ใน msg string
✗
log PII — email, card number, password
✗
plain text log ใน production
Best practices
✓
Structured JSON เท่านั้น
✓
trace_id ใน logger context ทุก request
✓
แยก fields ออกมา ไม่ใส่รวมใน msg
✓
ปิด debug ใน prod ด้วย log level config

Correlation
Investigation workflow — เริ่มที่ไหน ไปไหน
4 scenarios ที่พบบ่อยที่สุด
สถานการณ์เริ่มที่ตามด้วยสุดท้าย
User แจ้งว่า error Logs filter by user_id + error Trace via trace_id Metrics ดู scope ว่าเกิดแค่ user นี้หรือทั้งหมด
Alert: error rate สูง Metrics ดู trend + pattern Trace หา error spans Logs via trace_id เพื่อดู context ว่า "ทำไม"
Latency สูงผิดปกติ Metrics p95/p99 เทียบ baseline Trace หา slow spans ตัวไหนกิน time Profiles flame graph หา hot function
ข้อมูลเปลี่ยนผิดคาด Logs log_type=state_change + entity_id Trace via trace_id ดู call chain Audit logs ดู actor + ip + action
Third-party API ช้า / fail Logs log_type=external_call + provider Trace span HTTP client ดู duration Metrics external_call_duration_seconds p99
Key insight: ไม่มี signal ที่ดีที่สุดคนเดียว
แต่ละ signal ได้รับ "pass the baton" — Metrics ชี้ปัญหา → Trace หาจุด → Log อธิบาย → Profile แก้ performance root cause
